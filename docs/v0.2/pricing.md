# Ценообразование пакетов v0.2

> Модель: вариант B — готовые пакеты по диапазону площади. Клиент НЕ видит калькулятора, видит «коробочки».

## Формула расчёта пакета (внутренняя)

```
Себестоимость = Материалы + Работы мастеров + Операционные расходы
Цена пакета  = Себестоимость × 1.20  (маржа 20%)
```

**Что входит в каждую составляющую:**

### 1. Материалы (по каталогу из `material-catalog.md`)
- **Зависят от площади:** пол, обои/краска
- **Фиксированы по тарифу+теме:** двери, сантехника, освещение, кухня (Phase 2), текстиль (Phase 2)

### 2. Работы мастеров
- Каждый этап имеет длительность (см. `stages.md`) и сделочную ставку мастера
- Сумма по 23 этапам (для Базы — без дизайн-проекта, перегородок, Q3/Q4 → меньше этапов)
- **TBD: ставки мастеров за этап** — нужен реестр

### 3. Операционные расходы
- Логистика (закупка и доставка материалов)
- Супервайзер (часть зарплаты, отнесённая к проекту)
- Платёжные комиссии, налоги, страхование

## Диапазоны площади

```
Малая    : до 40 м²    (студия / 1-комнатная)
Средняя  : 41-60 м²    (1-2 комнаты)
Большая  : 61-80 м²    (2-3 комнаты)
XL       : 81-100 м²   (3+ комнаты)
> 100 м² : индивидуальный расчёт (не «коробочка»)
```

## Реализация в БД

### Таблица `tariff_packages`
```
id            uuid PK
tariff        text    -- 'base' | 'comfort'
color_scheme  text    -- 'light' | 'dark'
area_min      int     -- 0, 41, 61, 81
area_max      int     -- 40, 60, 80, 100
price         numeric -- цена пакета для этого диапазона
notes         text    -- что включено
active        boolean -- можно отключить пакет временно
created_at    timestamptz
updated_at    timestamptz
```

### Логика подбора пакета
```sql
SELECT * FROM tariff_packages
WHERE tariff = :selected_tariff
  AND color_scheme = :selected_scheme
  AND area_min <= :area
  AND area_max >= :area
  AND active = true;
```

Если `area > 100` → особый экран «Индивидуальный расчёт» с формой обращения.

### Связь с проектом
```
projects.tariff_package_id → tariff_packages.id
projects.total_price        ← копируется из package при создании
```

После подписания договора цена в `projects.total_price` фиксируется и не меняется (даже если в `tariff_packages` обновили цены).

## Открытые вопросы

1. **Ставки мастеров** — кто составляет реестр? Жёстко по этапам или по дням?
2. **Доплата за нестандарт** — что если у клиента, например, 4 двери вместо 3? Включаем в фикс. цену или доплата?
3. **Изменение состава пакета** — если клиент после подписания просит «давайте кварцвинил вместо ламината» (оба в каталоге) — без доплаты? Это и есть «жёстко задано ценой» из ответа Артёма.
4. **Изменение площади** — если замер показал 62 м² вместо 58 м² (попадаем в другой диапазон) — пересчёт?
