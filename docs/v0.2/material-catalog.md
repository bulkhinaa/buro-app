# Каталог материалов v0.2

> 2 тарифа × 2 темы = **4 каталога**. Цены — на момент составления каталога (требуют регулярного обновления).

## Видимость для клиента

| Что | Клиент | Супервайзер | Админ |
|---|---|---|---|
| Фото и название артикула | ✅ | ✅ | ✅ |
| Категория и тарифная привязка | ✅ | ✅ | ✅ |
| Цена за артикул | ❌ скрыто | ✅ | ✅ |
| Ссылка на поставщика | ❌ скрыто | ❌ | ✅ |

**Клиент видит только **что войдёт в его пакет** (фото + название), но НЕ цены и НЕ поставщиков.** Платформа сама закупает материалы — это часть фикс. цены пакета.

## Логика выбора клиента

В рамках выбранного тарифа+темы клиент **может выбрать** из 2-3 вариантов в каждой категории (например, тип напольного покрытия). Все варианты — в одной цене пакета (разница покрывается маржой).

Категории, где есть выбор:
- **Напольное покрытие** — ламинат / кварцвинил / ковролин
- **Декор стен** — обои или краска (если применимо)

Категории без выбора (автоматически):
- Двери, сантехника, освещение — один комплект на тариф+тему

## Архитектурные следствия для БД

### Таблица `material_catalog`
```
id              uuid PK
category        text       -- 'flooring' | 'doors' | 'decor' | 'plumbing' | 'lighting'
subcategory     text       -- 'laminate' | 'quartz_vinyl' | 'carpet' | ...
name            text       -- "Ламинат"
tariff          text       -- 'base' | 'comfort'
color_scheme    text       -- 'light' | 'dark'
price           numeric    -- внутренняя цена закупки (НЕ показываем клиенту)
unit            text       -- 'sqm' | 'piece' | 'box'
supplier_url    text       -- ссылка на поставщика (только для админки)
image_url       text       -- показываем клиенту
notes           text
client_choice   boolean    -- true = клиент выбирает из вариантов в этой категории
created_at      timestamptz
updated_at      timestamptz
```

**RLS-политика:**
- Клиент видит: `id, category, subcategory, name, tariff, color_scheme, image_url, client_choice` (без `price` и `supplier_url`)
- Супервайзер: то же + `price`
- Админ: всё

### Связь с проектом
Поле `projects.tariff` + `projects.color_scheme` определяет какие артикулы доступны клиенту.

### Связь с этапом
Каждый артикул прикреплён к этапу через `stage_materials` (М:М):
- Этап «Укладка пола» → артикулы категории `flooring` для выбранного тарифа+темы
- Этап «Чистовая электрика» → артикулы категории `lighting`
- Этап «Чистовая сантехника» → артикулы категории `plumbing`
- Этап «Установка дверей» → артикулы категории `doors`
- Этап «Декор/обои/покраска стен» → артикулы категории `decor`

### Расчёт цены пакета (внутренний)
```
Себестоимость материалов = (площадь × цена_пола)
                         + (кол-во_дверей × цена_двери)
                         + (площадь_стен × цена_обоев)
                         + (комплект сантехники и освещения)

Себестоимость работ = SUM(этап_длительность × сделочная_ставка_мастера)

Себестоимость = Материалы + Работы + Операционные

Цена пакета (для клиента) = Себестоимость × 1.20  (маржа 20%)
```

**Цена пакета формируется по диапазонам площади** (см. [pricing.md](./pricing.md)) — клиент НЕ видит формулу.
