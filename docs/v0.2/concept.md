# Концепция «Бюро ремонтов» v0.2

## Главное обещание

**Ремонт под ключ за 30 календарных дней** — фиксированный тариф, фиксированный срок, фиксированный набор материалов. Клиент не выбирает 200 артикулов — берёт готовый пакет с готовой цветовой схемой.

## Бизнес-модель

**Платформа = генподрядчик.**

```
Клиент платит платформе фикс. цену пакета
↓
Платформа гарантирует результат за 30 дней
↓
Платформа нанимает мастеров на этапы (внутренние сделочные ставки)
↓
Платформа закупает материалы по каталогу
↓
Супервайзер контролирует каждый этап (DoR/DoD)
```

**Маржа:** разница между ценой пакета (для клиента) и себестоимостью (работы мастеров + материалы + операционные).

**Юр. ответственность:** перед клиентом — у платформы. Перед платформой — у мастера (внутренний договор).

## Целевая аудитория

Владельцы квартир, которым нужен ремонт **«заехал/сдал»**:
- Чтобы заехать жить
- Чтобы сдавать в аренду без переделок

**НЕ для:** эстетов с индивидуальным дизайн-проектом и кастомом.

## USP

Три кита:
1. **30 дней под ключ** — главное обещание
2. **Фиксированный пакет** — клиент не думает (только тариф + тема)
3. **Супервайзер на каждом этапе** — контроль качества

## Процесс (единый стандарт для всех тарифов)

```
01. Замер
02. Выбор пакета + цветовой схемы
03. Фиксация комплектации
04. Смета и договор
05. Ремонт (поэтапно с приёмкой)
06. Комплектация «въезжай/сдавай»
07. Финальная уборка + вывоз мусора
08. Сдача с папкой «Что где установлено»
```

## Что входит в любой тариф

### Срок
До **30 календарных дней** при соблюдении стоп-листа и готовности объекта.

### Отделка (типовая)
- Натяжные потолки (везде)
- Стены Q2 (без контрового света / молдингов)
- Пол: только из списка пакета
- Свет: базовые типовые светильники (без треков / сложных сценариев)
- Двери

### Кухня и быт
- Кухня (типовые модули в наличии)
- Техника из пакета (стандартные модели, зависит от тарифа)
- Столешница ЛДСП

### Комплектация «въезжай/сдавай»
- Шторы / текстиль (минимальный набор)
- Базовые аксессуары по чек-листу

### Контроль
- Чек-лист приёмки по этапам (DoR / DoD)
- Фотофиксация работ и **скрытых работ** (минимально нужная)

### Финал
- Финальная уборка
- Вывоз мусора

### Подарок при сдаче — комплект «Что где установлено»
- Папка с информационной ведомостью (что где установлено, информация о счётчиках и т.д.)
- Инструкции по эксплуатации ко всей технике

## Тарифы

### Тариф 1 — База
**«Самый простой путь к готово»**

Приводим квартиру в аккуратный вид и доводим до состояния «заехал» или «сдал» — без долгих выборов и редких материалов.

| Категория | Что входит |
|---|---|
| **Пол** | Дешёвый кварцвинил (1-2 артикула/цвета) |
| **Стены** | Обои из ограниченного набора |
| **Двери** | «Тонкие/простые» из пакета + простая фурнитура |
| **Сантехника / смесители** | Базовый набор |
| **Кухня / техника** | Минимальный комплект (например, варочная/духовка ИЛИ варочная/микроволновка — выбираете 1 стандарт) |

### Тариф 2 — Комфорт
**«Чтобы было как для себя — и всё равно быстро»**

Собираем цельный интерьер в одной схеме и комплектации, чтобы по возвращении можно было жить или спокойно сдавать без доделок.

| Категория | Что входит |
|---|---|
| **Пол** | Кварцвинил лучше (другой класс/коллекция) или ламинат |
| **Стены** | Обои лучше или краска по Q2 (один вариант) |
| **Двери** | Классом выше |
| **Сантехника / смесители** | Лучше набор / визуально приятнее |
| **Кухня / техника** | Расширенный набор (например, посудомойка как опция внутри тарифа) |

### Только 2 тарифа (решение Артёма от 04.05.2026)

## Цветовые схемы

Для каждого тарифа доступны **2 готовых сценария**:

### Светлая тема
Тёплые нейтрали, светлый пол, светлые обои/краска.

### Тёмная тема
Контраст без сложного света (тёмные акценты).

> ⚠️ **Важное правило:** цветовая схема = **фиксированный набор артикулов** (обои/краска/пол/двери/кухня/шторы). Иначе 30 дней не выдержать.

**Итого:** 2 тарифа × 2 темы = **4 готовых пакета**.

## Модель ценообразования

### Готовые пакеты по диапазону площади (вариант B)
Клиент НЕ видит калькулятора с ценой за м². Он видит **готовые «коробочки»**:

```
База Светлая до 40 м²  = X ₽
База Светлая до 60 м²  = Y ₽
База Светлая до 80 м²  = Z ₽
... и так для всех 4 пакетов и диапазонов
```

Клиент при оформлении заявки указывает площадь → система показывает один соответствующий диапазон с фиксированной ценой. **Без расчётов и сравнений.**

### Выбор материалов внутри пакета
Внутри тарифа+темы клиент **может выбрать** из 2-3 вариантов в каждой категории (см. каталоги материалов). Например, в Базе Светлой:
- Пол: ламинат (450 ₽/м²) **или** кварцвинил (633 ₽/м²) **или** ковролин (460 ₽/м²)
- Все варианты входят в цену пакета (разница в материалах закрыта маржой)

> Это даёт клиенту **ощущение выбора** при сохранении фиксированной цены пакета и срока 30 дней.

### Расчёт цены пакета (внутренняя формула)
```
Себестоимость = (материалы по каталогу) + (работы мастеров по сделочным ставкам)
Цена пакета  = Себестоимость × 1.20  (маржа 20%)
```

### Закупка материалов
**Закупает платформа.** Клиент не видит ссылок на поставщиков, не общается с ними. Это упрощает клиентский путь и убирает зависимость от наличия материалов у внешних поставщиков.

### Кухня и текстиль
В MVP пока **не включаются в каталог** (нет конкретных артикулов). Будут добавлены в Phase 2 после согласования с поставщиками.

## Условия, при которых месяц реалистичен

1. 🛠 Объект **без перепланировки**
2. 🔑 **Стабильный доступ** на объект для мастеров и доставок
3. 👨‍🍳 Решения **выбираются из меню**, без «а давайте ещё вот это»
4. 🚛 Материалы из пакетов **в наличии** / с быстрыми поставками
